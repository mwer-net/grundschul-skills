# Sprachsensible Materialgestaltung (DaZ und Bildungssprache)

Sprache ist in jedem Fach Lernmedium und Hürde. Viele Kinder (nicht nur DaZ) scheitern an der Aufgabenformulierung statt am Inhalt.

## Scaffolding im Material

Hilfen so viel wie nötig, so wenig wie möglich – und abbaubar:

| Hilfe | Einsatz |
|---|---|
| **Wortspeicher** | Fachwörter mit Artikel und Bild am Rand oder als Karte ("der Würfel", "die Kante") |
| **Satzanfänge / Satzmuster** | "Ich vermute, dass …", "Zuerst …, dann …, zum Schluss …", "Das Ergebnis ist …, weil …" |
| **Bild-Wort-Zuordnung** | Neue Begriffe immer mit Bild einführen |
| **Beispiel** | Erste Aufgabe vorgelöst ("So geht's") |
| **Lückentext** mit Wortauswahl | Vorstufe zum freien Schreiben |
| **Gegliederte Schreibrahmen** | Für Versuchsprotokolle, Beschreibungen, Briefe |

## Formulierungsregeln

- Hauptsätze, Aktiv, Präsens. Max. ca. 10 Wörter pro Satz in Klasse 1/2, ca. 15 in Klasse 3/4.
- Gleiche Dinge gleich benennen (nicht "Plättchen" und dann "Chips").
- Nomen mit Artikel angeben; bei DaZ optional Artikelfarbe (der blau, die rot, das grün – Klassenkonvention prüfen).
- Keine Redewendungen, Ironie, Abkürzungen.
- Pronomen sparsam, lieber das Nomen wiederholen.

## Operatoren (Arbeitsaufträge) Grundschule

Einheitlich nutzen und mit Symbol verknüpfen:

| Operator | Bedeutung für Kinder |
|---|---|
| lies | Text mit den Augen oder laut lesen |
| schreibe (auf/ab) | etwas aufschreiben / abschreiben |
| male (an) / zeichne | farbig gestalten / mit Stift darstellen |
| kreise ein / kreuze an | markieren |
| verbinde | Linie ziehen |
| ordne zu | passend zusammenbringen |
| ergänze | Fehlendes einsetzen |
| rechne | Ergebnis ausrechnen |
| vergleiche | Gleiches und Unterschiede finden |
| beschreibe | genau sagen/schreiben, wie etwas ist |
| erkläre / begründe | sagen, warum ("…, weil …") |
| vermute | denken, was passieren wird |
| prüfe / kontrolliere | nachsehen, ob es stimmt |
| erzähle | mündlich darstellen |

Operatoren ab Klasse 3 schriftlich schrittweise einführen ("beschreibe", "begründe"), in Klasse 1/2 vor allem handlungsnahe Verben. Erklären und Begründen (●●●, Reflexion) in Klasse 1/2 mündlich oder mit Satzanfang ("Ich weiß es, weil …").

## Mehrsprachigkeit als Ressource

- Gelegentlich Wörter in den Herkunftssprachen der Kinder sammeln lassen (Wortspeicher mehrsprachig).
- Bilder und Namen aus verschiedenen Kulturen.
